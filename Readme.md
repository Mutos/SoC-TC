# The Hoshikaze 2250 universe ported into NAEV.

Stars of Call (SoC) is a TC aiming at bringing your screen the Hoshikaze universe.

As of 2026, it has been developped into novels, short stories, a tabletop Role-Playing Game, several illustrations and a set of goodies. It also features a wiki on our website, containing more than 1000 articles.

For years now, there has also been a videogame, named Stars of Call, which used NAEV 0.6 several years ago, and is now running under 0.8. The goal of this TC is to upgrade SoC to an up-to-date version of NAEV. We have chosen the 0.14 beta as it was current when we started the conversion project.

Warning : for now, SoC is just a map of the Hoshikaze universe (2000+ systems, 900+ spobs) and a Llama to explore it. No trade, no combat, no factions interaction, no Hoshikaze-specific ships, all these will be progressively introduced. There will also be new things in the map, notably new stations and unlandable spobs for background in uninhabited systems. We work on the map in synch with the wiki, modify it on the Naev 0.8 version, then convert in bulk the map to the Naev 0.14 version.

This is a love-fueled project, developped in our hobby time, so don't expect progress to be exceedingly fast... neither furious...

==== Using this repository by hand

	Warning : it's way better to get it directly from Naev's Plugin Manager !

1/ Download and run NAEV from https://naev.org/

2/ Clone this repository into the NAEV plugins folder :
- Linux		~/.local/share/naev/plugins
- MacOS		~/Library/Application Support/org.naev.Naev/plugins
- Windows		%APPDATA%\naev\plugins

3/ Run NAEV and launch the Plugin Manager

4/ In the Plugin Manager, select the "Stars of Call" TC and exit

5/ The game should prompt you to restart, answer Yes and you're on it !
